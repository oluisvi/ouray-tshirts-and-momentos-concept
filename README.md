# Ouray T-Shirts and Momentos — independent website concept

Mobile-first multi-page visitor website concept, with an illustrated responsive board (`prancha.html`) for desktop, tablet and phone.

## Pages

- `index.html` — shop overview, real shop photography, editorial categories and route to visit
- `find.html` — non-transactional guide to broad product themes
- `story.html` — illustrative Ouray/San Juan travel context
- `visit.html` — public listing address and phone, map directions, shop contact and winter shipping caveat
- `credits.html` — factual limits, references and image-use notes

## Local preview

Run a static server from this folder, for example `python -m http.server 4175`, then open `http://localhost:4175/`.

## Presentation board

Open `prancha.html` at 1600×1120 to see the responsive desktop/tablet/mobile device presentation. A PNG export is in `arte/`.

## Notes

This is an independent concept, not an official site. Product categories are editorial; inventory, prices, sizes and checkout are not represented. The lead confirmed winter shipping, but terms remain to be asked. Photo-reuse approval is pending. See `BRIEF_DO_PROJETO.md` and `ASSET_CREDITS.md`.
